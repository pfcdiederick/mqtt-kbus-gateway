      COM1

      The gateway forwards COM1 transparently over MQTT (kbus/serial/com1/...): every received frame is one rx message, tx/set sends bytes as they are. The settings are made on the client side: CODESYS publishes them (baudrate/set, format/set, framegap/set); this page only shows them (read only). RS-232 / RS-485 is set in the WBM (Interfaces > Serial Interface, owner "None").

      COM1 is off in the gateway (SERIAL_DEVICE empty), or the gateway has not published it yet.

      MQTT Topics

      Topics on the Broker
      TopicValueUpdated

      Everything the page receives: kbus/#. Command topics (…/set, e.g. kbus/do/1/set) are not listed: they are requests to change something; the row without /set (kbus/do/1) is the actual state. To change outputs: log in, press Take Control, then click the value of kbus/do/<n> (true/false) or kbus/ao/<n> (0–65535), type the new value and press Enter (Esc = cancel). Another program that writes the same outputs cyclically (e.g. CODESYS) overwrites them in its next cycle.
