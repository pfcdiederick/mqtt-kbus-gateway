MQTT clients connected to this broker

Live values from the MQTT broker of this controller: the page subscribes only to kbus/# (kbus-gateway) and bridge/status (mqtt-bridge). The connected clients come from the broker's connection log (mqtt-manager); another client on this controller is shown as CODESYS. Outputs are switched with kbus/do/<n>/set by your applications; from this page only with the control mode switched on (gear wheel, top right). If an application writes the outputs cyclically (e.g. CODESYS), it overrides clicks made here.
